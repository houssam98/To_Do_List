To-Do List Avancée

An interactive, responsive To-Do List web application featuring modern Glassmorphism UI designs, dynamic task management, responsive progress tracking, and celebratory animations upon completing all tasks.

⚠️ Notice: I lost access to my previous GitHub/repository account (HoussamMaj81/To_Do_List), so I retrieved this project from it and reposted it here under my current account.

✨ Features

Task Management: Add, edit (double-click on task text), delete, and check off tasks.

Dynamic Task Filtering: Seamlessly filter tasks by All, Active, and Done.

Interactive Progress Bar / Bottle:

Displays a visual liquid indicator that fills up as you complete your tasks.

Dynamically adapts to vertical glass-bottle view on desktop screens and horizontal progress bar on mobile screens.

Real-Time Analytics: Live counter summarizing Total, Pending, and Completed tasks.

Completion Celebration: Displays a celebratory overlay with inspirational quotes when all current tasks are completed.

Responsive Design: Mobile-friendly layout styled with custom CSS glassmorphism properties.

🛠️ Built With

HTML5

CSS3 (Glassmorphism design, Flexbox, Animations, Responsive Media Queries)

JavaScript (Vanilla JS) (DOM Manipulation, Dynamic Filtering, State Management)

🚀 Getting Started

Clone or Download the Repository:

git clone https://github.com/houssam98/To_Do_List.git


Run the Project:
Open projetJavaScript.html in any modern web browser. No complex setup or build tools required!

💡 Usage Highlights

Adding a Task: Type your task into the input box and press Enter or click the Add button.

Editing a Task: Double-click on any existing task text to turn it into an input field, then press Enter to save the edit.

Completing a Task: Click the checkbox next to a task. Watch the progress liquid level rise!

Deleting a Task: Click the trash emoji (🗑) button next to the task.
